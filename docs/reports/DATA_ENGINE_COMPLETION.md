# Task 04 — Korean Knowledge Data Engine completion report

Date: 2026-10-24

## Result

The end-to-end, rights-gated data-engine vertical slice is operational:

`PDF → raw layout → OCR decision → segmentation → knowledge candidates → validation → persistence → review → quality report/export/API`

This report does **not** claim completion of the six textbook datasets. Their
processing/reuse rights are unverified, so they remained local, untracked and
unprocessed.

## Delivered

- Conservative Unicode normalization: NFC display text, Korean whitespace,
  Vietnamese diacritics, NUL/control filtering, stable track/source keys.
- Extensible OCR protocol plus a no-guess default adapter that returns
  `unresolved`; OCR is requested only for missing/damaged image-backed text.
- Owner-scoped sentence identity separated from sentence occurrence, with
  incremental/idempotent persistence and orphan-safe deletion.
- Owner-scoped review queue and decisions (`pending_review`, `approved`,
  `rejected`, `unresolved`) with `ContentReview` history.
- Dialogue API with ordered turns; existing lesson, vocabulary, grammar,
  sentence, reading, exercise and listening APIs retained.
- Approved-by-default export for vocabulary JSON/CSV, grammar JSON, sentence
  JSONL, dialogue/reading/exercise/listening JSON. Every export carries schema,
  source, extraction version, review status and timestamp metadata.
- Expanded quality report for source, structure, vocabulary, grammar, exercises,
  listening, provenance, review status and per-lesson counts. No unsupported
  accuracy metric is fabricated.
- CI now runs PostgreSQL 16 migrations/tests for the Task 04 branch and stacked
  PR, along with audits and the web production build.

## Remaining limitations and unresolved work

- No production OCR backend is configured; image-only regions are surfaced as
  unresolved rather than guessed. A deployment must implement `OcrAdapter`.
- No licensed, human-reviewed textbook ground truth was available; therefore
  full-book completeness and semantic accuracy are unknown.
- Current deterministic structured parsers are strongest on known section/table
  layouts and fixture markers. New real layouts require a licensed pilot,
  source comparison, extractor tuning and rerun before expansion.
- Topic/level enrichment, related-grammar graphs, vocabulary variants/parts of
  speech and broad exercise-type recognition require source evidence and remain
  future vertical slices.
- The API records review decisions; a reviewer UI and multi-user identity/roles
  are not implemented. Authentication remains a single-owner bearer boundary.
- Audio is `available` only when an asset reference exists; this task does not
  supply textbook audio, TTS, STT or AI-generated answers.

Code completion is therefore verified for this bounded vertical slice; textbook
data completion is explicitly **not** claimed.
